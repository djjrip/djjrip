## 🚀 Featured Architecture: GG LOOP B2B Platform

**Role:** Technical Founder & Operations Lead
**Stack:** AWS (App Runner, RDS, Kinesis, S3), Node.js, PostgreSQL, Docker

Instead of building a simple CRUD app, I architected GG LOOP to handle enterprise-grade data loads and strict operational security requirements. 

**Key Technical Achievements:**
- **Data Pipeline:** Engineered a robust 45-table PostgreSQL data warehouse on AWS RDS, managing 33,800+ lines of production code linking C++ core game systems with Node.js microservices.
- **Real-Time Telemetry:** Implemented AWS Kinesis Data Streams for high-velocity extraction, transformation, and loading (ETL) of live client telemetry.
- **Automated Deployments:** Fully dockerized the environment and built CI/CD pipelines via GitHub Actions deploying seamlessly to AWS App Runner, reducing release cycles by 40%.
- **Zero-Trust Security:** Hardened the architecture by securing IAM roles, mitigating IDOR vulnerabilities, managing API authentication middleware, and rotating compromised secrets across the stack.
