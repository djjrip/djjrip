## 🚀 What I'm Building
 
### [GG Loop](https://ggloop.io) — B2B Gaming Rewards Platform
> *Live in Production*
 
A full-stack competitive gaming rewards SaaS platform where businesses integrate gameplay mechanics into real-world reward programs. Built and operated solo.
 
- ⚙️ **Backend:** Express + TypeScript REST API on AWS App Runner
- 🗄️ **Database:** PostgreSQL RDS with Drizzle ORM and SSL-enforced connections
- 🖥️ **Desktop:** Tauri (Rust) native client with OS keychain security and foreground-window anti-cheat
- 📡 **Telemetry:** Real-time event streaming via AWS Kinesis
- 🔄 **CI/CD:** Fully automated GitHub Actions pipelines — build, test, and deploy on every push
